# TP4 Génie Logiciel – Système de Réservation Aéroportuaire

## Description
TP4 réalisé à l'ISIMA/UCA (L3 Informatique) dans le cadre
du cours de Génie Logiciel. Modélisation et implémentation
d'un système de réservation aéroportuaire en Java.

## Fonctionnalités
- Gestion des aéroports, compagnies et vols
- Gestion des escales
- Système de réservation clients et passagers
- États de réservation (EtatReservation)

## Technologies
Java, Gradle, IntelliJ IDEA

## Auteurs
Asmae Kaysouny, Chebbi, Bellara
